## Проверить результат самостоятельно

```bash
# правила: отступы, углы, связность, формулы, вертикальные просветы
python3 tools/validate_result.py <входной.geojson> <выходной.geojson>

# состав файлов по схемам
check-jsonschema --schemafile docs/schema/input.schema.json  <входной.geojson>
check-jsonschema --schemafile docs/schema/result.schema.json <выходной.geojson>

# тесты решения
mvn -o test
```

## Наборы данных

| Набор | Что показывает |
|---|---|
| `data/samples/contest_dataset.geojson` | конкурсный набор организаторов, 17 точек присоединения |
| `data/samples/contest_result.geojson` | его расчёт: три варианта, лучший — 1 901 м |
| `data/samples/depth_demo_dataset.geojson` | тот же район с газопроводами и кабелем: на нём виден профиль по глубине |
| `data/samples/moscow_case_dataset.geojson` | синтетический набор другого района: своя застройка, дороги, железная дорога, река; у существующей сети заданы расходы, поэтому виден расчёт влияния на неё |
| `data/samples/moscow_case_reference.geojson` | эталонная трасса к нему — как проложил бы инженер |
| `tools/make_test_dataset.py` | генератор проверочного набора любого объёма на основе конкурсного, с другим составом точек |
| `tools/make_large_dataset.py` | генератор файла до 3 ГБ для проверки требования 3.2 |
| `tools/make_moscow_case.py` | генератор набора другого района вместе с эталонной трассой |

Синтетические наборы построены генератором и не являются выгрузкой из рабочих систем — это указано
внутри самих файлов.
