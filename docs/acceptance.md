# Что заявлено и чем подтверждено

Таблица для проверяющего: каждое утверждение о решении — и способ убедиться в нём самостоятельно.
Команды выполняются из корня репозитория, стенд — http://13.143.181.167/.

## Свойства решения

| Утверждение | Состояние | Чем подтверждено |
|---|---|---|
| Работает офлайн | выполнено | образ собирается один раз, во время работы внешних вызовов нет; стенд поднят в закрытом контуре |
| Один и тот же вход даёт один и тот же выход | выполнено | повторные прогоны в `ContestDatasetTest` и на стенде дают совпадающие длину, стоимость и S |
| Результат прослеживается до входного файла | выполнено | блок `metadata` в выходе: SHA-256 входа, число объектов, время расчёта, режим, методы, редакция приложения |
| Правила меняются без программиста | выполнено | `GET /api/rules/*`, правка YAML, `POST /api/rules/reload`; профиль водопровода в `rules-profiles/` работает тем же кодом |
| Два метода поиска сравнимы напрямую | выполнено | `routing_method`, `routing_millis`, `engineering_millis`, `turns_per_km` в сводке; таблица сравнения на вкладке «Сравнение» |
| Нарушения не скрываются | выполнено | самопроверка пишет `CLEARANCE_TIGHT`, `TURN_LIMIT`, `TREE_CROSS`, `DEPTH_CLEARANCE`; вариант с нарушением помечается `notes` и не выдаётся, пока есть чистая альтернатива |
| Решение проверяется независимо от сервиса | выполнено | `tools/validate_result.py` — 23 проверки на вариант, 25 в режиме глубины; JSON Schema на вход и выход |
| Ограничения названы прямо | выполнено | [limits.md](limits.md): допущения, единственное расхождение с приложением (железная дорога), что не делается |

## Известные ограничения

| Что | Подробности |
|---|---|
| Геометрия на незнакомых данных | на сгенерированном наборе другого района инженерный вариант оставляет поворот 167° — он помечен в `notes` и в диагностике, но он есть; растровый и видимостный варианты на том же наборе чисты |
| Граф видимости в плотной застройке | на конкурсном наборе две из девяти стратегий графа видимости дают развороты и в выдачу не попадают; метод остаётся полезен как второй взгляд, но не как единственный |
| Реконструкция существующей сети | не выполняется: отменена разъяснениями организаторов от 21.09.2026, п. 14. Влияние на существующую сеть считается информационно |
| Рельеф | в режиме глубины поверхность принимается условно горизонтальной — так требует приложение |

## Как проверить самому

```bash
# 1. расчёт конкурсного набора
curl -F "file=@data/samples/contest_dataset.geojson" \
     "http://13.143.181.167/api/process?methods=all" -o result.geojson

# 2. независимая проверка правил
python3 tools/validate_result.py data/samples/contest_dataset.geojson result.geojson

# 3. проверка состава файла по схеме
check-jsonschema --schemafile docs/schema/result.schema.json result.geojson

# 4. тесты решения
mvn -o test
```

Ожидаемое: 69 проверок валидатора без замечаний на двумерном расчёте, 75 — в режиме глубины;
19 тестов, из них один помечается пропущенным (прогон файла 3 ГБ запускается отдельно).
