# 001. Java 11 и Spring Boot 2.6.3

**Контекст.** Команда сильнее в Python: геоаналитика, shapely, networkx. ТЗ раздел 3 фиксирует стек:
Java 11, Spring Boot 2.6.3, Maven, PostgreSQL, docker-compose 1.29.2. Требование появилось 15.09,
когда план был на Python.

**Решение.** Следуем ТЗ буквально и переписываем на Java. Геометрия — JTS, перепроекция — proj4j,
описание API — springdoc-openapi 1.7.0 (последняя версия, совместимая со Spring Boot 2.6).

**Следствия.** Потеряли день на переписывание. Взамен сервис собирается и запускается на стенде
проверяющего без оговорок, а версии в `pom.xml` и `docker-compose.yml` совпадают с указанными
в задании. Python остался только в инструментах проверки — они не входят в сервис и не влияют
на его запуск.
