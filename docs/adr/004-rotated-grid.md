# 004. Сетка разворачивается на азимут застройки

**Контекст.** Кварталы Москвы редко стоят строго по сторонам света. Сетка, выровненная по осям
координат, вынуждает трассу идти «лесенкой» вдоль наклонных проездов: много поворотов, лишние метры
и геометрия, непохожая на работу проектировщика.

**Решение.** Преобладающее направление застройки и существующей сети определяется автоматически
(на конкурсном наборе — 69,1°), и окно поиска разворачивается на этот угол.

**Следствия.** Трасса идёт длинными прямыми вдоль проездов, а повороты получаются прямыми.
Азимут можно задать вручную параметром правил, если автоматическая оценка не подходит.
