# 005. Нормативная часть в YAML

**Контекст.** Таблицы 1 и 2 приложения, цены метра, отступы, коэффициенты специальных проходов
и углы пересечения меняются: редакция приложения вышла 21.09 и изменила часть правил прямо в ходе
хакатона. Зашитые в код числа означают пересборку сервиса на каждое изменение.

**Решение.** Вся нормативная часть — в `src/main/resources/rules/*.yml`, у каждого правила заполнено
поле `source` с указанием, откуда взято число. Правила читаются на старте и перечитываются
по `POST /api/rules/reload`, отдаются наружу через `GET /api/rules/*`.

**Следствия.** Новая редакция свода правил — правка файла, а не релиз. Эксперт видит на вкладке
«Правила расчёта» ровно то, по чему считал сервис. Дополнительный эффект: другой ресурс
(водопровод) получается сменой профиля правил без единой правки кода.
