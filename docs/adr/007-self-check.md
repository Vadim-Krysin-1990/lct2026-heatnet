# 007. Самопроверка и отбор вариантов без нарушений

**Контекст.** Экспертиза начинается с проверки обязательных правил: нарушение геометрии
обесценивает хороший показатель. Алгоритм может оставить поворот круче 90°, если фаску некуда
вписать, или провести ствол ближе нормы после смены диаметра.

**Решение.** После сборки варианта идёт самопроверка по фактическим диаметрам: отступы, повороты,
пересечения новых участков вне узлов, вертикальные просветы. Нарушения попадают в диагностику
(`CLEARANCE_TIGHT`, `TURN_LIMIT`, `TREE_CROSS`, `DEPTH_CLEARANCE`), вариант получает пометку в
`notes`, и в выдачу он не идёт, пока в его категории есть вариант без нарушений.

**Следствия.** Сервис сам говорит о проблеме вместо того, чтобы её прятать. Цена — иногда в выдачу
попадает вариант с чуть худшим показателем; это сознательный обмен: соблюдение правил важнее
десятых долей S.
