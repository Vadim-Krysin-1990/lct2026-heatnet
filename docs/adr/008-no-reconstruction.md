# 008. Реконструкция существующей сети не выполняется

**Контекст.** Пункт 2.11 ТЗ требовал распространять расходы по существующей сети, определять
требуемые диаметры, участки под реконструкцию и необходимость реконструкции камер. Разъяснения
организаторов от 21.09.2026, п. 14, прямо сняли это: «в актуальной расчётной модели реконструкция
существующей тепловой сети и существующих камер не выполняется».

**Решение. **Реконструкция убрана из расчёта и из выходных данных: отдельных объектов
реконструкции нет, в стоимость она не входит. При этом сам расчёт влияния сохранён как
информационный: добавленный расход распространяется по цепочке к источнику, определяется требуемый
диаметр, участки с нехваткой помечаются (`existing_network_impact`).

**Следствия.** Результат соответствует актуальной модели оценки, а служба эксплуатации всё равно
видит, каким участкам существующей сети не хватит диаметра. Если организаторы вернут реконструкцию,
понадобится добавить стоимость и объекты — данные для этого уже считаются.
