# 009. Просмотрщик — один HTML-файл

**Контекст.** ТЗ не требует интерфейса, но показать результат нужно: карта, варианты, смета,
профиль. Сборка фронтенда (npm, bundler, node_modules) — это ещё одна инфраструктура, которая
должна собраться на машине проверяющего и работать офлайн.

**Решение.** Просмотрщик — один HTML-файл с Leaflet, без сборки и без пакетного менеджера.
Раздаётся nginx, данные берёт из того же REST, что и внешние системы.

**Следствия.** Витрина не может «не собраться», запускается одной строкой и не входит в оцениваемый
контур — сервис работает и без неё. Ограничение: файл большой и правится текстом, автотестов на
интерфейс нет.
