# 010. Доступ ИИ-агента через MCP

**Контекст.** Расчёт объясним, но чтобы получить объяснение, нужно открыть интерфейс или разобрать
GeoJSON руками. Специалисту удобнее спросить словами: «сравни методы», «где существующей сети
не хватит диаметра».

**Решение.** Поверх того же REST сделан MCP-сервер (`mcp/catp_mcp_server.py`): 12 инструментов,
стандартная библиотека Python, без внешних зависимостей. Операций записи в наборе нет, кроме
постановки расчёта в очередь.

**Следствия.** Языковая модель работает с фактическими результатами расчёта, а не с общими словами,
и каждое обращение попадает в журнал событий. Сервис от этого не зависит: MCP — отдельный процесс,
который можно не запускать.
